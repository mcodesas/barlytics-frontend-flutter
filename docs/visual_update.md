# Mejora visual BarLytics Flutter

Esta versión mejora la experiencia visual y la usabilidad del frontend:

- Paleta de colores más viva para móvil, tablet y web.
- Login con fondo degradado, tarjeta central y mensajes claros.
- Menú lateral renovado con íconos, colores por módulo y navegación más intuitiva.
- Inicio tipo dashboard con tarjetas de acceso rápido.
- Listados con cabecera visual, buscador, contador de registros, tarjetas móviles y tabla web mejorada.
- Formularios más claros, con tarjetas, campos en una o dos columnas según tamaño de pantalla y botones visibles.
- Detalles tipo ficha, con datos agrupados en tarjetas.
- Ayudas de búsqueda más amigables, con buscador y selección visual.
- Estados vacíos, carga, error y confirmación con componentes más coloridos.

La funcionalidad se mantiene disponible para todos los dispositivos soportados. El dispositivo solo adapta la presentación visual.
