# BarLytics Colombia — checklist de lanzamiento SEO

Este archivo contiene acciones externas que no pueden completarse únicamente modificando el código.

## Después del despliegue

- Verificar que `https://barlytics.com.co/` sea el dominio canónico definitivo y que HTTP y cualquier variante `www` redirijan con 301 a la versión elegida.
- Comprobar respuesta HTTP 200 para `/`, `/software-para-bares/`, `/funcionalidades/`, `/planes/`, `/descargas/`, `/contacto/` y `/preguntas-frecuentes/`.
- Abrir `https://barlytics.com.co/robots.txt` y `https://barlytics.com.co/sitemap.xml` desde Internet.
- Dar de alta/verificar la propiedad de dominio en Google Search Console.
- Enviar `https://barlytics.com.co/sitemap.xml` en Search Console.
- Inspeccionar las siete URLs públicas y solicitar indexación cuando corresponda.
- Revisar periódicamente Indexación > Páginas, Core Web Vitals y Rendimiento filtrando por país Colombia.
- Medir específicamente las consultas `barlytics`, `barlytics colombia`, `software para bares colombia` y variaciones relevantes.
- Mantener el nombre de marca **BarLytics** y la URL oficial consistentes en perfiles empresariales y redes oficiales.
- No crear perfiles, reseñas, backlinks o páginas por ciudad de forma artificial.

## Punto de atención de marca

Existe otra aplicación internacional que utiliza el nombre “Barlytics”. Para diferenciar la entidad colombiana, mantener de forma consistente **BarLytics**, **BarLytics Colombia** y `barlytics.com.co` en el sitio y en los perfiles oficiales legítimos.
