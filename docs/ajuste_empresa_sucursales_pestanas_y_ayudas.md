# Ajuste visual empresa -> sucursales

## Cambio aplicado

Se mejoró el flujo de creación de empresas para que visualmente quede claro que es un proceso por pasos:

1. Datos de empresa.
2. Sucursales.
3. Finalizar.

En el formulario de creación de empresa se muestra una navegación visual tipo pestañas/pasos dentro de la tarjeta principal. El botón principal cambia a **Guardar y continuar**.

Al guardar la empresa, el usuario pasa a la pantalla de sucursales, donde se mantiene la misma navegación visual interna con el paso 2 activo.

## Ayudas en sucursales

En la creación de sucursales dentro del flujo de empresa se reemplazaron los campos manuales por ayudas de búsqueda para:

- Ciudad.
- Zona horaria.
- Moneda.
- País teléfono.

Esto evita que el usuario escriba IDs técnicos.
